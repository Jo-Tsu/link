# Smallink 产品全量走查报告

日期：2026-08-20
范围：macOS 客户端、Python Core/API、SQLite 数据层、智能体运行时、连接器、记忆与治理、自动化、构建和测试。

## 1. 结论

Smallink 当前是一个可运行、可构建、核心闭环可验证的 Beta 产品，不是只靠 Mock 数据演示的原型。会话、工具执行、模型 Provider、Skill、权限审批、运行中心、自动化、MineM 连接器、原始数据池、AI 治理、正式记忆和记忆注入均有真实代码与持久化支撑。

目标产品仍未全部完成。主要缺口是 MineM 应用中心与素材工作台、通用多智能体编排、知识库与混合检索、Postgres 唯一事实源，以及少量治理和记忆管理能力。

## 4. 本次修复

1. 修复断开服务时按 Enter 仍提交消息、清空草稿并可能进入永久等待的问题。
2. 修复数据源权限新增、切换或删除失败后界面一直处于忙碌状态的问题。
3. 修复会话右栏泄漏已隐藏 Slack、GitHub 等连接器的问题，统一执行 MineM-only 展示策略。
4. 修复 MineM 描述尚未加载时显示为错误名称 `Minem` 的问题。
5. 移除启动页对隐藏连接器状态的不必要请求。
6. 消除右栏产物列表和连接器页面的重复轮询，减少启动和切页负担。
7. 修复正式记忆只读取 global/workspace、遗漏当前 session 作用域的问题。
8. 补齐候选记忆批量接受/忽略后端事务入口和客户端批量交互，支持部分失败反馈。

## 5. 剩余问题与优先级

### P1：目标闭环缺口

1. **MineM 应用中心尚未实现**：当前只有连接、状态和启动能力，没有 `system:minem` 默认项目、素材管理、素材对话和沉淀闭环。
2. **知识库与检索尚未完成**：记忆目前是关键词召回，缺少文档切片、向量索引、混合排序和可解释引用。
3. **Postgres 尚未成为唯一事实源**：当前 SQLite 适合个人 Beta，但与目标技术架构存在差距。
4. **通用多智能体编排未完成**：已有 Explorer 子运行可视化，缺少通用委派、依赖、并行、预算和父子取消。

### P2：完整性与体验

1. 候选记忆支持批量接受/忽略，但批量调整类型尚未完成。
2. 正式记忆缺少归档与恢复。
3. AI 治理仍主要由用户触发，后台增量调度和失败任务中心需要补齐。
4. 启动阶段仍有少量重复读取数据根目录的请求；不影响正确性，但可继续合并为共享缓存。
5. 旧连接器适配代码仍保留在后端以便未来恢复，客户端已经隐藏；后续应建立清晰的功能开关，而不是散落条件判断。
6. 现有 E2E 依赖 Mock，需增加至少一条启动真实 Core 的桌面关键路径测试。

## 6. 建议开发顺序

1. 完成 `system:minem` 默认项目、MineM 素材管理与对话闭环。
2. 建设知识条目、切片和混合检索，同时复用现有来源证据模型。
3. 完善记忆归档、批量改类型和治理后台调度。
4. 抽象通用多智能体编排协议，并让 Explorer 迁移为同一协议的首个实现。
5. 设计 SQLite 到 Postgres 的可回滚迁移，再把 Postgres 切换为唯一事实源。
