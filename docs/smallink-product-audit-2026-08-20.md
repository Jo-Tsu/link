## 5. 剩余问题与优先级

### P1：目标闭环缺口

1. **Postgres 尚未成为唯一事实源**：当前 `link.db`、`automation.db` 和少量 JSON 适合个人 Beta，但与目标技术架构存在差距；禁止在没有校验和回滚点时直接双写切换。
2. **MineM 完整嵌入工作台尚未完成**：第一版素材主流程可用，但 Public UI API、Workspace Bridge、故事线、标签治理和复杂编排仍需 MineM 提供稳定契约。
3. **向量语义召回尚未完成**：知识已有切片、BM25 和可解释词法混合排序，但还没有 pgvector 向量候选与语义排序。
4. **高级多智能体调度尚未完成**：通用只读委派已可用，依赖图、预算、父子取消、失败重试和跨任务调度仍待建设。

### P2：完整性与体验

1. 记忆冲突任务、提示词评估和治理质量指标尚未完成。
2. 启动阶段仍有少量重复读取数据根目录的请求；不影响正确性，但可继续合并为共享缓存。
3. 旧连接器适配代码仍保留在后端以便未来恢复，客户端已经隐藏；后续应建立清晰的功能开关，而不是散落条件判断。
4. 现有 Playwright E2E 使用真实前端和网络层 Fake API；仍需增加至少一条启动真实 Core 的隔离桌面关键路径。
5. MineM 写入 E2E 尚未执行，必须先建立不会污染用户素材的 `APPTEST-*` 隔离数据集。

## 6. 建议开发顺序

1. 按 [Smallink Postgres 迁移运行手册](./smallink-postgres-migration-runbook.md) 完成 SQLite/JSON 到 Postgres 的快照、校验、影子读和可回滚切换。
2. 与 MineM 协作完成 Public UI API、Workspace Bridge 和完整领域 Surface。
3. 在 pgvector 上增加向量候选，与现有可解释词法排序组合并做检索评估。
4. 增加 AgentRun 依赖图、预算、父子取消、失败重试和断线续传游标。
5. 完成冲突任务、提示词评估、真实 Core 桌面 E2E 和隔离 MineM 写入 E2E。
