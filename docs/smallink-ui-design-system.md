# Smallink 品牌视觉与 UI 设计系统

文档版本：1.2  
生效日期：2026-07-27  
适用范围：Smallink macOS 客户端、Web 客户端、安装界面、产品截图、图表与品牌物料

## 1. 设计目标

Smallink 采用“清透冰蓝空间 + 深邃科技蓝节点”的品牌体系：

- 深蓝表达专业、安全和长期可信，但不作为浅色主题的大面积默认底色。
- 科技蓝表达数据流动、连接和系统结构。
- 青蓝表达可操作节点、当前焦点和实时反馈。
- 云雾白与冰蓝渐变提供主要工作空间，保证高密度信息仍然清晰。

产品是高频使用的个人 AI 工作系统。视觉必须克制、可扫描、可重复操作，不能为了科技感牺牲信息密度、可读性或操作确定性。

## 2. 品牌色彩体系

| 色彩角色 | 色彩名称 | HEX | RGB | CMYK | 主要用途 |
|---|---|---|---|---|---|
| Primary | 深邃夜蓝 Deep Navy | `#00224D` | `0, 34, 77` | `C100 M80 Y30 K40` | Logo 主体、重要标题、深色模式结构和小面积品牌节点 |
| Secondary | 科技蓝 Tech Blue | `#00529B` | `0, 82, 155` | `C95 M65 Y5 K0` | 次级按钮、卡片边框、渐变过渡、图表主色 |
| Accent | 节点青蓝 Cyan Node | `#00A8E8` | `0, 168, 232` | `C75 M15 Y0 K0` | 关键 CTA、选中状态、数据节点、焦点与实时反馈 |
| Gradient | 空间流光 Space Flow | `#00224D -> #00A8E8` | 135 度线性渐变 | - | Logo、关键 CTA、加载动画和小面积品牌节点 |

### 2.1 中性与语义扩展色

| 令牌 | 浅色模式 | 深色模式 | 用途 |
|---|---|---|---|
| `panel` | `#FFFFFF` | `#111C31` | 卡片、弹窗、输入区 |
| `heading` | `#00224D` | `#F8FAFC` | H1、H2、H3 |
| `body` | `#0F172A` | `#F8FAFC` | 正文 |
| `muted` | `#64748B` | `#A9B8CA` | 次要信息 |
| `border` | `#E2E8F0` | `#203858` | 常规边框 |
| `border-strong` | `#CBD5E1` | `#31557E` | 强调边框和控件边界 |
| `success` | `#00529B` | `#29B6E8` | 完成、可用、已验证 |
| `warning` | `#8A6116` | `#D6B56B` | 等待、提醒，保持低饱和 |
| `danger` | `#B94A5A` | `#E7808F` | 错误、删除和中断，保持低饱和 |

外部连接器 Logo 保留各自品牌色，不强制染成 Smallink 蓝色；其容器、边框、选中态和交互反馈仍使用 Smallink 令牌。

侧栏搜索等高频熟悉动作使用图标按钮收纳，默认不显示文字；必须提供悬停提示和无障碍名称，点击后打开完整操作界面。

## 3. 60-30-10 色彩比例

### 60% 背景与空间

- 浅色模式使用白色、`#F8FAFC` 与极浅冰蓝渐变。
- 深色模式使用 `#0F172A` 和 `#111C31`。
- 主要内容区允许大面积低对比渐变，但相邻色阶差必须很小，不能影响正文和数据阅读。

### 30% 结构与品牌

- 浅色主题的侧边栏和核心导航使用白色到冰蓝的渐变，不使用整块 `#00224D`。
- 页面标题、重要结构线和主要图表使用深邃夜蓝或科技蓝。
- 卡片边框在浅色模式保持中性，在深色模式使用科技蓝的低透明度版本。

### 10% 交互与焦点

- `#00A8E8` 只用于关键 CTA、选中态、当前节点、实时状态和键盘焦点。
- 同一视口内避免同时出现多个大面积青蓝色块。
- Hover 微光只出现在可操作焦点，不作为静态装饰。

## 4. 字体与排版

### 4.1 字体族

- 西文：`Inter`, `Helvetica Neue`, `Arial`, 系统无衬线字体。
- 中文：`PingFang SC`, `Microsoft YaHei`, `Noto Sans SC`。
- 代码与数据：`JetBrains Mono`, `Fira Code`, `SF Mono`。
- 品牌字标：保留 Smallink Logo 原稿；客户端文本字标使用内置 `Manrope 700`。

### 4.2 字号与字重

| 层级 | 字号 | 字重 | 颜色 | 使用范围 |
|---|---:|---|---|---|
| H1 | `32px` | Bold | `heading` | 首页问候、内容型一级标题 |
| H2 | `24px` | Semi-Bold | `heading` | 页面标题、连接器详情标题 |
| H3 | `18px` | Medium | `heading` | 面板与主要分区标题 |
| Body | `14-16px` | Regular | `body` | 正文、对话和表单信息 |
| Meta | `12px` | Regular | `muted` | 时间、状态、辅助说明 |

工作台、设置和运行中心属于高频工具界面。紧凑面板不得机械套用 32px；应根据容器职责使用 H2 或 H3。所有界面文字字间距为 `0`，不使用负字距。

## 5. 圆角、边框与阴影

- 按钮、标签、输入框和小控件：`8px`。
- 卡片、弹窗和大型工具容器：`16px`。
- 头像、状态点和节点图标容器：`50%` 正圆。
- 浅色卡片：白色背景、`1px #E2E8F0` 边框、低强度深蓝阴影。
- 深色卡片：`#111C31` 背景、科技蓝低透明度边框，可使用极轻内高光。
- 不允许卡片嵌套卡片；页面分区优先使用无边框布局或全宽结构带。

## 6. 组件规范

### 6.1 侧边栏与导航

- 浅色主题使用 `#FFFFFF -> #F7FBFF -> #EDF8FC` 的纵向轻渐变，深邃夜蓝只用于字标和重要标题。
- Logo 可放入半透明云雾白正圆节点容器；App/Dock 图标仍保持透明底独立图形。
- 默认文字使用深钛灰，辅助信息使用中灰，不在浅色侧栏使用大面积反白文字。
- Hover 使用低对比的科技蓝到青蓝渐变。
- 当前节点、注意力提示和主要新建按钮使用节点青蓝。
- 当前选中行使用连续的浅青蓝渐变，并在左侧显示 2px 节点青蓝标记；强色只出现在当前项，不让普通导航行持续着色。
- 展开态宽度为 264px；收起态保留 56px 图标栏，不允许整栏消失后仅依赖边缘 Hover。
- macOS overlay 收起态为交通灯预留 84px 列宽和 54px 顶部净空；首个按钮不得与原生窗口控件重叠。
- 收起态至少保留展开、新建会话、搜索、连接器、运行中心、自动化和设置；图标必须具有 tooltip、无障碍名称和当前页状态。
- 展开态与收起态不得同时出现同一操作的重复按钮，避免点击目标和窗口拖动区域冲突。

### 6.1.1 Skill Hub 创建区

- 顶部使用“导入”“新建 Skill”“对话创建”三个明确操作；对话创建是品牌渐变主按钮，其他为中性次按钮。
- 创建弹窗使用单层 16px 容器、固定头尾和中间可滚动内容，不在弹窗内部嵌套装饰卡片。
- 保存范围使用二段选择，“我的 Skills”与“当前项目”必须同时说明可见范围；无工作区时项目选项禁用并解释原因。
- 文件夹导入使用原生目录选择器，界面显示选择路径但不要求非技术用户手工输入路径。
- 输入焦点使用完整的 3px 节点青蓝焦点环；错误使用低饱和危险色信息带。

### 6.2 按钮

- Primary：`#00529B -> #00A8E8` 渐变 + 白色文字。
- Secondary：白色或面板背景 + 科技蓝边框/文字。
- Danger：低饱和红，仅用于破坏性操作。
- 图标按钮优先使用标准图标；按钮文字只用于明确命令。

### 6.3 卡片与弹窗

- 16px 圆角，避免多层嵌套。
- 选中卡片使用科技蓝边框和青蓝焦点，不使用大面积实心青蓝。
- 弹窗必须保留明确标题、关闭按钮、滚动区域和键盘焦点。

### 6.4 输入框

- 默认边框使用 `border`，Focus 使用节点青蓝三像素焦点环。
- 复合输入容器由最外层统一绘制完整圆角焦点环，内部 `textarea`、按钮和下拉控件不得重复绘制或裁切焦点边框。
- 错误状态使用低饱和危险色，不与节点青蓝争夺视觉焦点。
- Placeholder 使用 `muted`，不能低于可读性阈值。

### 6.5 状态与图表

- 运行中：节点青蓝，并允许轻量脉冲。
- 完成：科技蓝或亮科技蓝。
- 等待：低饱和警告色。
- 失败：低饱和红。
- 图表主序列按 Deep Navy、Tech Blue、Cyan Node 顺序使用；语义警告色只用于异常数据。

## 7. 渐变、微光与动效

- 品牌渐变：`linear-gradient(135deg, #00224D 0%, #00529B 52%, #00A8E8 100%)`。
- 页面渐变：`linear-gradient(145deg, #FBFDFF 0%, #F6FBFF 52%, #EEF9FD 100%)`。
- 侧栏渐变：`linear-gradient(160deg, #FFFFFF 0%, #F7FBFF 48%, #EDF8FC 100%)`。
- 卡片渐变：白色到 `#F4FAFF`，色差必须轻微。
- 选中渐变：青蓝 15% 透明度到科技蓝 6% 透明度，并配合左侧 2px 标记。
- 渐变可以用于页面、侧栏、顶部玻璃层、重点卡片、输入区和 CTA，但内容承载面必须保持低对比；高饱和品牌渐变仅用于小面积操作点。
- 深色背景中的节点青蓝可使用 `0 0 12px rgba(0, 168, 232, 0.4)` 微光。
- 微光只在 Hover、Focus、运行中和启动状态出现，不作为静态背景装饰。
- 常规过渡为 `140-200ms`；支持 `prefers-reduced-motion`。

## 8. 对比度与可访问性

- 节点青蓝 `#00A8E8` + 深邃夜蓝 `#00224D`：`5.81:1`。
- 深邃夜蓝 `#00224D` + 云雾白 `#F8FAFC`：`15.02:1`。
- 深钛灰 `#0F172A` + 云雾白 `#F8FAFC`：`17.06:1`。
- 科技蓝 `#00529B` + 白色：`7.84:1`。
- 状态不能只依赖颜色，必须同时提供文字、图标或形状。

## 9. 使用禁忌

### Do

- 使用白色、云雾白和冰蓝渐变建立清透空间。
- 数据流、连接线和当前节点使用节点青蓝反馈。
- 保持 60% 中性空间，让高价值内容成为主角。

### Don't

- 不在大面积正文中使用高对比或高饱和渐变。
- 不在浅色主题中将深邃夜蓝作为整块侧栏或整页底色。
- 不让青蓝 CTA、成功状态和普通链接同时大面积出现。
- 不把高饱和暖色与主色等比例并置。
- 不改变外部连接器的品牌 Logo 颜色。
- 不在小尺寸 App 图标中加入 `Smallink` 英文字样。
