# Smallink 应用中心与 MineM 首个应用测试计划

文档版本：1.1  
更新日期：2026-08-09  
状态：目标测试与发布门禁  
关联文档：[产品 PRD](./smallink-app-center-minem-prd.md)、[技术设计](./smallink-app-center-minem-technical-design.md)

## 1. 测试目标

验证 Smallink 应用中心和 MineM 首个应用形成真实闭环：

```text
启用应用
→ 创建唯一系统项目
→ 自动连接 MineM CLI
→ 加载完整 MineM 素材工作台
→ 专属对话和工作台调用真实能力
→ 资料和运行事实沉淀
→ 写操作人工确认
→ MineM 生成正式素材
→ Smallink 返回可打开产物
→ AI 生成有来源的候选记忆
→ 用户确认后进入正式记忆
→ 后续会话召回
```

测试必须证明真实数据、真实 CLI 和真实持久化链路可用，不允许只通过 Mock 页面截图判定完成。

## 2. 范围

### 2.1 纳入范围

- App Manifest 和 Registry；
- 应用中心列表和 MineM 详情；
- MineM 实例发现、启用、启动、检查、停用；
- `system:minem` 默认项目；
- MineM 专属会话和智能体；
- 现有六个只读能力；
- 页面生成、发布、汇报创建和导出；
- 后续页面插入、替换、移动和移出；
- 权限、确认和审计；
- SensoryRecord、素材引用和内容快照；
- 去重、幂等、部分成功和重启恢复；
- 候选记忆、人工确认和后续召回；
- macOS 客户端完整交互。
- MineM 工作台、汇报、页面、案例、资源、故事线、导入任务和素材治理；
- Public UI API、Workspace Bridge 和可嵌入前端契约；
- 预览、版本、编排、标签、重复合并、安全删除、演讲稿和 HTML/PDF 导出；
- 工作台语义操作事件及其向 SensoryRecord 的映射；
- 对话与工作台双向携带对象上下文。

### 2.2 首期排除

- 应用商店支付和第三方分发；
- 云端多设备同步；
- 未正式开放的第二个应用；
- MineM 未版本化私有 HTTP API 和数据库直连；
- 复制后由 Smallink 独立维护的 MineM 前端分叉。

## 3. 测试原则

1. 单元测试验证规则，不依赖真实 MineM。
2. 合约测试验证 Smallink 和 MineM CLI 的机器协议。
3. 集成测试使用临时状态目录和可控 Fake CLI。
4. 端到端测试必须覆盖真实 Smallink Desktop 和真实 MineM.app。
5. 写入测试使用隔离测试素材和唯一前缀，禁止污染用户正式汇报。
6. 所有失败场景都验证 UI、持久化和重试行为，不只验证错误码。
7. 发布前必须完成重启恢复、幂等和来源追溯测试。

### 4.3 测试数据

固定数据集：


- 英文标题；

- 50 页以上汇报；

- 版本在读取后发生变化。

## 6. 单元测试

### 6.1 App Manifest

- 合法 MineM 清单加载成功；
- 重复 `app_id` 被拒绝；
- 重复 `system_project.project_id` 被拒绝；
- 未知 `schema_version` 被隔离但不阻塞 Smallink 启动；
- 缺失默认智能体被拒绝；
- 清单引用未注册能力被拒绝；
- 待建设能力不会被前端 API 返回；
- 应用名称和文案支持中英文。

### 6.2 App Registry

- 注册顺序不影响结果；
- MineM 只注册一次；
- 禁用应用不从历史数据中删除；
- 清单升级保留实例和系统项目；
- Registry 不执行 CLI 或启动外部应用。

### 6.3 系统项目

- 首次启用创建 `system:minem`；
- 重复启用执行 upsert；
- 并发启用只生成一个项目；
- `workspace_path` 保持 `NULL`；
- 普通文件夹项目不能占用 `system:minem`；
- 系统项目不能通过普通删除接口永久删除；
- 停用设置状态但保留会话、资料和记忆来源。

### 6.4 MineM Adapter

- CLI 发现优先级正确；
- 应用包 CLI 可执行时优先使用；
- 用户 CLI 所有者或权限不安全时拒绝；
- 命令使用参数数组且不经过 Shell；
- 自动追加 `--output json --no-input`；
- 审批前不会添加 `--confirm`；
- 超时返回统一错误；
- 非 JSON 返回统一错误；
- 大输出触发裁剪或 Blob 保存；
- 非 loopback URL 被移除；
- Token 字段被脱敏；
- 取消信号终止等待并记录取消状态。

### 6.5 Capability Registry

- 能力名唯一；
- 只读和写入风险分类正确；
- 模型不能传入二进制路径；
- 模型不能传入任意命令名；
- 参数 Schema 拒绝未知高风险字段；
- MineM 未启用时能力不装配；
- 普通项目可按会话开关 MineM，但不改变系统项目归属。

### 6.6 数据去重

- 相同素材 ID 和版本只产生一个 `app_asset_ref`；
- 相同内容哈希只产生一个快照；
- 新版本产生新引用或版本记录；
- 重复搜索保留两条查询事实；
- 刷新列表不重复保存正文；
- CLI 重试保留运行记录但不重复创建正式资产映射。

### 6.7 记忆策略

- 工具名、路径和随机 ID 不会单独成为候选记忆；
- 单次短期页面指令默认不升级为长期偏好；
- 多次一致修改可以合并为偏好；
- 候选缺少来源时被拒绝；
- 相同 `merge_key` 合并而不是重复新增；
- 未确认候选不进入正式记忆；
- 接受、编辑、合并和忽略动作均保留审计。

## 7. MineM CLI 合约测试

### 7.1 协议基础

对真实 CLI 或固定协议 Fixture 执行：

```text
status
agent capabilities
asset search
asset get
asset versions
asset lineage
report pages
page build
report create
report export
```

断言：

- JSON 顶层结构稳定；
- `schemaVersion=minem.cli/v1`；
- 错误码可映射；
- 素材 ID、编号、版本和链接可提取；
- `report pages` 的真实页面编号可以从当前返回结构中正确归一化；
- 50 页以上结果不会突破模型上下文限制；
- CLI 版本不兼容时 Smallink 阻止写操作。

### 7.2 写操作合约

- `page build` 可以只生成草稿；
- `page build --publish --wait` 返回正式页面引用；
- `report create` 返回正式汇报引用；
- `report page add/replace/move` 无 `--confirm` 时不能修改正式汇报；
- `report export --wait` 返回可验证的文件或任务引用；
- 旧页面和旧版本在替换后仍存在；
- 不存在素材返回 `not_found`，不会自动创建替代品。

## 7A. MineM Workspace 与 Public UI API 合约测试

### 7A.1 版本协商

- `workspace_contract=minem.workspace/v1` 可被 AppHost 加载；
- `ui_api_protocol=minem.ui-api/v1` 与生成客户端类型一致；
- `capability_set` 缺少核心能力时显示不兼容，不静默隐藏入口；
- MineM 版本高于或低于支持范围时进入只读诊断状态；
- 断线重连后对象 ID、当前路由和未完成任务可恢复。

### 7A.2 完整能力对齐矩阵

每个受支持 MineM 发布版本必须产出机器可读能力清单，并逐项验证：

| 领域 | 合约与行为 |
|---|---|
| 工作台 | 统计、最近素材、分类和任务状态来自真实服务 |
| 汇报 | 列表、搜索、筛选、分页、详情、重命名、安全删除、故事线、演讲稿和导出 |
| 编排 | 拖拽、插入、多选、隐藏、恢复、移出、确认和并发冲突 |
| 页面 | 预览、标签、来源、历史、版本、主版本、页面角色和组合预览 |
| 案例 | 案例组、详情、导入、更新和引用保护删除 |
| 资源 | 图片、Logo、图标、SVG、GIF、视频的预览、分类、标签、版本和导入 |
| 故事线 | 创建、版本、来源汇报、查看和反向创建汇报 |
| 导入任务 | 排队、运行、成功、失败、取消、重试和批次来源 |
| 素材治理 | 标签体系、AI 标签、重复分析、合并、版本提升和谱系 |
| 演示与导出 | 整份预览、演讲稿、本地朗读、HTML ZIP、PDF、进度和失败重试 |

能力对齐测试必须同时断言功能可交互、真实数据变化、错误可恢复和 MineM 原客户端可看到同一结果。

### 7A.3 Bridge 合约

- 主题、语言、路由和焦点同步正确；
- `continueConversation` 只传稳定对象引用，不传不受控 HTML；
- 对话产物可定位到工作台对象和当前版本；
- 文件选择、目标目录和高风险审批由 Smallink 外壳处理；
- Bridge 不接受 Shell、数据库路径或任意外部 Origin；
- 语义事件包含应用、项目、对象、版本、动作和时间，不包含鼠标坐标流。

## 8. 集成测试

### 8.1 启用应用

步骤：

1. 使用空状态目录启动 Smallink Core；
2. 请求启用 MineM；
3. Fake CLI 返回健康状态；
4. 再次请求启用。

断言：

- 一条 `app_instance`；
- 一个 `system:minem`；
- MineM 默认智能体已注册；
- 六个只读能力可用；
- 状态事件顺序正确；
- 第二次启用不重复写入。

### 8.2 自动启动

覆盖：

- MineM 已运行；
- MineM 已安装但未运行；
- MineM 启动缓慢；
- MineM 启动超时；
- CLI 缺失；
- CLI 与服务版本不兼容；
- MineM 启动后动态端口变化。

断言 Smallink 不缓存长期端口，且失败不会阻塞其他 API。

### 8.3 搜索与读取

步骤：

1. 在 `system:minem` 会话搜索素材；
2. 打开其中一个页面；
3. 重复搜索并再次打开；
4. MineM 返回该页面新版本；
5. 再次读取。

断言：

- 查询事实保留；
- 素材卡片字段正确；
- 同一版本快照不重复；
- 新版本有新快照；
- 来源链可以回到会话和 CLI 运行。

### 8.4 页面和汇报创建

步骤：

1. 用户要求创建三页汇报；
2. Agent 生成草稿；
3. 用户拒绝首次发布；
4. Agent 根据意见修改；
5. 用户确认；
6. MineM 创建页面和汇报；
7. Smallink 返回产物卡片。

断言：

- 拒绝前 MineM 无正式新素材；
- 修改原因进入原始事实；
- 确认后只创建一次；
- 卡片可打开真实预览；
- 页面、汇报、运行和审批关系完整；
- AI 回复不显示裸 JSON 或编码路径。

### 8.5 部分成功

模拟页面发布成功、汇报创建失败。

断言：

- 运行状态为 `partial`；
- 已创建页面可查看；
- UI 显示未完成步骤；
- 重试只创建汇报；
- 页面不会重复发布。

### 8.6 停用和重新启用

- 停用后 MineM 工具不再装配；
- 历史会话和产物引用仍可查看；
- 新写操作明确提示应用已停用；
- 重新启用复用原实例和系统项目；
- 重新检查 MineM 真实状态。

## 9. 端到端测试

### E2E-001 首次启用

1. 打开应用中心；
2. 只看到真实 MineM 应用；
3. 启用 MineM；
4. 打开“MineM 素材库”；
5. 创建新对话。

通过条件：导航可继续使用，状态进度明确，项目只出现一次。

### E2E-002 自动启动 MineM

1. 退出 MineM；
2. 进入 MineM 项目；
3. 输入搜索请求。

通过条件：Smallink 显示启动过程，自动唤起 MineM，连接后继续原请求，无需再次输入。

### E2E-003 和素材库对话

输入：

> 找出适合老板看的产品架构页面，并说明选择原因。

通过条件：

- 返回真实结果；
- 卡片有编号、版本和来源；
- 点击预览有效；
- 来源详情可查看本次搜索和读取运行。

### E2E-004 创建正式汇报

输入：

> 用这些页面创建一份三页 Smallink 产品汇报。

通过条件：

- 先展示计划和预览；
- 确认前不写正式汇报；
- 确认后 MineM 中出现唯一汇报；
- Smallink 产物卡片可以预览、打开 MineM 和导出。

### E2E-005 修改和替换页面

通过条件：

- 显示旧页面、新页面和影响页槽；
- 用户确认后替换；
- 旧版本仍可查看；
- 来源链包含修改原因和审批。

### E2E-006 会话归属

1. 在 MineM 项目创建多个会话；
2. 重启 Smallink；
3. 展开 MineM 项目。

通过条件：全部会话仍在项目下，同时可在最近会话出现，不存在无归属副本。

### E2E-007 记忆闭环

1. 在至少两次修改中表达相同偏好；
2. 运行治理；
3. 打开候选记忆来源；
4. 编辑并确认；
5. 创建新 MineM 会话。

通过条件：候选说明价值和来源，新会话只在相关任务中召回已确认版本。

### E2E-008 重启恢复

在以下状态分别重启 Smallink：

- MineM 启动中；
- 页面构建中；
- 等待确认；
- MineM 写入后、Smallink 尚未保存最终结果。

通过条件：状态被恢复或进入可解释人工检查，不重复写入。

### E2E-009 完整素材工作台

1. 打开 `system:minem`；
2. 依次进入工作台、汇报、页面、案例、资源、故事线、导入任务和素材治理；
3. 在每个模块完成一次真实读取或管理动作；
4. 重启 Smallink 后重新进入相同对象。

通过条件：所有模块位于 Smallink 内并真实可操作，MineM 客户端可看到同一领域状态，没有 Mock 数字、空点击或必须跳出客户端才能完成的核心步骤。

### E2E-010 对话与工作台双向交接

1. 在页面详情点击“继续对话”；
2. 智能体读取该页面稳定 ID 和版本并生成新版本；
3. 从产物卡片打开工作台；
4. 返回页面详情确认新版本、来源和历史。

通过条件：上下文不依赖标题猜测，双向跳转定位同一对象，工作台与对话共享任务和版本状态。

### E2E-011 管理闭环

使用隔离测试数据依次完成导入、标签修改、重复分析、手工合并、主版本提升、汇报拖拽编排、演讲稿生成、HTML/PDF 导出和安全删除检查。每一步都验证进度、取消/重试、来源、版本和影响提示。

## 10. 故障注入测试

- CLI 进程不存在；
- CLI 权限不足；
- CLI 启动后立即退出；
- stdout 为空；
- stdout 为非法 JSON；
- stdout 超过限制；
- stderr 包含敏感信息；
- MineM 返回未知 Schema；
- 动态端口清单损坏；
- MineM 在调用中重启；
- 素材在确认前被其他操作更新；
- Smallink 在确认后写入前崩溃；
- Smallink 在 MineM 成功后持久化前崩溃；
- Blob 磁盘空间不足；
- 数据库暂时锁定；
- 用户取消长任务。

每个故障必须断言：用户文案、运行状态、数据一致性、可重试性和重复资产数。

## 11. 安全测试

### 11.1 命令注入

尝试在 query、name、reference、destination 中输入：

- Shell 分隔符；
- 子命令替换；
- 换行；
- 绝对二进制路径；
- `--output` 和 `--confirm` 覆盖参数。

通过条件：参数作为单一值传递或被 Schema 拒绝，不产生额外命令。

### 11.2 路径权限

- 未授权目录导入被阻止；
- 用户确认目录后可导入；
- `../` 越界被拒绝；
- 导出只能写到确认目标；
- 系统项目没有伪造文件系统权限。

### 11.3 数据与日志

- Token 字段不进入日志和 SensoryRecord；
- 未选择素材正文不发送给模型；
- 非 loopback 预览 URL 不被信任；
- 应用停用后不能通过旧会话绕过能力门禁；
- 前端不能直接调用未注册的 MineM 写接口。

## 12. 性能测试

| 场景 | 目标 |
